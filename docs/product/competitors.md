# 競合調査

旅行計画アプリの競合を調べた結果です。調査日は 2026-11-06 です。各サービスの機能は公開ページの説明をもとにしており、実際に使って確かめたものではありません。

## 競合度が高い 5 サービス

| サービス | 主な機能 | 企画との近さ |
| --- | --- | --- |
| [AVA Travel](https://travel.ava-intel.com/app/) | 行きたいスポットを選んで地図上に集める、AI による旅行プランの自動生成、友達との共同編集 | ユーザーの流れ全体が非常に近い |
| [Funliday](https://www.funliday.com/posts/funliday-app-function-guide/) | AI による旅程作成、地図上でのスポット管理とルート確認、複数人での共同編集 | AI と地図を使った旅行計画 |
| [TravelCanvas](https://travelcanvas.app/ja) | URL で友達を招待して共同編集、行きたい場所の提案といいね投票、インストールとアカウント登録が不要 | 全員で候補を出して決める仕組み |
| [GroupTripper](https://grouptripper.app/) | 旅行アイデアの共有、メンバーによる投票、旅程の共同編集 | グループ全員で計画を進める |
| [Truce](https://truceapp.com/) | 全員による候補の提案と投票、投票結果にもとづく意思決定、スケジュールと費用の管理 | 幹事への負担集中を解消するという課題意識 |

## 分かったこと

AI による旅程作成、地図上でのスポット管理、共同編集、投票は、すでに複数のサービスにある。機能の有無では差別化できない。

一方、「3D マップ上にスポットを建築し、みんなで旅行を組み立てていく」体験を中心にしたサービスは、調べた範囲では見つからなかった。差別化の軸は、旅行計画を便利にすることより、計画そのものを楽しくし、普段は計画に参加しない人も巻き込むことに置く。

## 残っている調査

- AVA Travel、Funliday、TravelCanvas は機能が近いので、実際に触って体験の違いを詳しく調べる
