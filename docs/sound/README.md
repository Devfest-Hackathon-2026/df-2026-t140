| SEコーディネーターの管理項目 | このアプリで確認したいこと |
| --- | --- |
| 目的・感情 | 操作受付、発見、達成、注意のどれか。利用者に何を感じてほしいか |
| 発音タイミング | 押した瞬間／サーバー受付／画面への出現／演出の着地のどこか |
| 聞こえる対象 | 操作した本人だけか、旅を開いているほかのメンバーにも鳴るか |
| 画面ごとの扱い | 招待中・しおり閲覧中・旅の再生中でも建築通知を鳴らすか |
| 優先順位と同時発音 | 完成・検索結果・シャッターが重なったとき、何を優先するか |
| 連打・大量発生への対応 | クールダウン、同時発音数、複数件をまとめる条件 |
| 重複防止 | 再描画・再接続・画面の開き直しで同じイベントを鳴らさない |
| 長さ・余韻・音量 | 頻繁な操作ほど短くする。完成音でも次の操作を邪魔しない |
| 音色の統一 | 日常操作は丸いポップ・バブル・低い丸音。保存のぴろりんと場面音は役割を保つ |
| 繰り返しへの耐性 | 何十回聞いても疲れないか。必要なら数種類のバリエーション |
| 音と映像の同期 | 建物の出現や写真の表示と、音のアクセントが合っているか |
| ミュート・音量設定 | 設定の入口、保存範囲、通知音と演出音を分ける必要性 |
| 音が出ない場合の体験 | 音なしでも、受付・成功・失敗を画面で判断できるか |
| 端末・ブラウザ確認 | 最初の操作後の再生、バックグラウンド復帰、スマホ実機での聞こえ方 |
| 音源の納品仕様 | ファイル形式、容量、先頭の無音、ループの有無、命名、版管理 |
| 権利・出典 | 商用利用・加工・再配布の条件、必要なクレジット |
| 試聴条件 | スマホのスピーカーとイヤホン、小音量、会話しながらの利用で確認 |
